---
description: A comprehensive workflow to plan, build, debug, and perfect code using multiple skills sequentially.
---

1. Understand the problem and explore solutions using the `@brainstorming` skill.
2. Structure the brainstormed ideas into a concrete, atomic plan using the `@concise-planning` skill.
3. If the task involves user interfaces or styling, apply the `@ui-ux-pro` skill (or `@ui-ux-pro-max` if available) to ensure premium aesthetic design and alignment.
4. Apply the expert skill associated with the primary language of the task (e.g. `@cpp-pro`, `@python-pro`, `@flutter-expert` or the relevant Systems Programming Pack) to write robust, idiomatic code.
5. If any bugs, test failures, or UI lags are encountered during execution, immediately stop and use the `@systematic-debugging` skill to find the root cause before attempting fixes.
6. Run linting and validation steps (e.g. `flutter analyze` or `@lint-and-validate` if available) to ensure the code is perfectly clean and standard-compliant.
7. Apply the `@kaizen` skill to perform a final continuous improvement pass: add Poka-Yoke error proofing, clean up comments, and ensure code is not over-engineered.
